# Узнай песню

Музыкальная игра для компании: угадайте песню по изображению и выберите один из четырёх вариантов.

- 241 песня с индивидуальными изображениями, вдохновлёнными названием и настроением песни.
- Подборки: все песни, 85 песен под гитару, 26 любимых песен и English hits.
- Партии на 10, 20 или 30 картинок, без повторов внутри партии. Если подборка меньше, используются все её картинки.
- Одиночная игра: 100 очков за правильный ответ, серия попаданий, разбор ошибок и рекорд в текущем браузере.
- Игра с телефонами: комната ведущего, QR-приглашение, вход по нику и до 10 участников.
- Правильный ответ: `max(0, 100 − floor(время / 1 секунду))`. Например, за 5 секунд — 95 очков. Неверный ответ, отсутствие ответа и окончание 100 секунд — 0.
- Общий рейтинг после каждой третьей песни и в конце партии. Равенство очков разрешается по числу верных ответов, затем суммарному времени на верные ответы.
- Клавиши 1–4 для ответа, Enter для перехода после ответа.
- Адаптивный интерфейс для телефона, компьютера и телевизора. Кнопка полного экрана работает, если её поддерживает браузер.

Изображения созданы с помощью ИИ. Это самостоятельные интерпретации песен, а не официальные обложки или однозначные ребусы. Аудиозаписи и тексты песен не включены.

## Запуск

Опубликованная игра запускается обычным JavaScript-файлом с каталогом внутри него. Загрузка отдельных `.mjs`-модулей или `songs.json` для старта не требуется. Сетевой режим и его библиотеки инициализируются по нажатию. При ошибке загрузки или запуска появляется сообщение и кнопка «Обновить игру»; ожидание ограничено 12 секундами.

После изменения исходников пересоберите опубликованное приложение:

```sh
npm ci
npm run build
```

Сборка создаёт `app.<hash>.js` и `startup.<hash>.js`, обновляет ссылки в `index.html`. Имена с хешами позволяют браузеру получать новые версии без смешивания старых модулей.

```sh
python -m http.server 8767 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8767/ . На телефонах используйте опубликованную HTTPS-версию: адрес `127.0.0.1` относится к самому устройству.

## Компания с телефонами

1. Ведущий открывает игру на компьютере или телевизоре, выбирает подборку и длину партии, нажимает «Играть с телефонами».
2. Участники сканируют QR, вводят имя и ждут в комнате. Можно войти вручную по коду.
3. Ведущий начинает партию. После загрузки картинки у всех начинается общий отсчёт через 3 секунды.
4. У каждого один ответ. Ведущий считает время получения ответа. Результат открывается после всех ответов, по истечении 100 секунд или по команде ведущего.
5. Ведущий переключает картинки и рейтинги. Его вкладка должна оставаться открытой до конца партии.

Это анонимные профили с именем в браузере, без паролей, восстановления аккаунта на другом устройстве и общего рейтинга между вечеринками. Возврат с прежним именем в прежнюю комнату на том же браузере сохраняет очки, пока ведущий держит её открытой. Новые участники входят до начала партии.

Сайт размещается целиком на GitHub Pages. [PeerJS Cloud](https://peerjs.com/client/faq) бесплатно устанавливает соединение; состояния комнаты передаются через WebRTC между браузерами. Постоянная база и собственный сервер не используются. При несовместимой сетевой конфигурации или VPN прямое соединение может не установиться; попробуйте общую Wi-Fi-сеть. При закрытии или обновлении вкладки ведущего комната теряется. Результаты относятся к текущей комнате.

PeerJS 1.5.5 и QRCode 1.5.4 включены локально в `vendor/realtime.mjs`; во время игры скрипты с CDN не подгружаются. Лицензии зависимостей сохранены в `vendor/THIRD_PARTY.txt`.

## Проверки

```sh
npm test
```

Проверяются состав данных, наличие изображений, уникальность вопросов и ответов, начисление очков, защита от двойного ответа, завершение партии, раздельные рекорды, границы секунд, общий запуск после загрузки, скрытие ответа, возврат участника, ограничения комнаты и рейтинги после 3/6 песен и в финале.

## Публикация

GitHub Pages: ветка `main`, корень репозитория. Все пути относительные, поэтому игра работает в подкаталоге Pages.

Источником для механики стала игра [Mamma Mia Quiz](https://mupamuc.github.io/ITALLIANO_QUIZ/). Реализация и оформление созданы для этой музыкальной игры.

Состав публичного репозитория: код, названия песен и сжатые ИИ-изображения. Локальная музыкальная библиотека и настройки караоке в публикацию не входят.
