# Узнай песню

Основной адрес: **https://sim.fpimi.ru/karaoke/**. Игра, картинки, фотоальбом, музыка и комнаты размещены на VPS `leanhub`. HTTPS обслуживает Caddy; сервис комнат слушает `127.0.0.1:8102`.

Музыкальная игра для компании: угадайте песню по изображению и выберите один из четырёх вариантов.

- 241 песня с индивидуальными изображениями, вдохновлёнными названием и настроением песни.
- Подборки: все песни, 85 песен под гитару, 26 любимых песен и English hits.
- Партии на 10, 20 или 30 картинок, без повторов внутри партии. Если подборка меньше, используются все её картинки.
- Одиночная игра: 100 очков за правильный ответ, серия попаданий, разбор ошибок и рекорд в текущем браузере.
- После верного ответа автоматически звучат 15 секунд оригинальной песни. После ошибки или пропуска фрагмент можно включить вручную.
- Начало фрагментов взято из меток первого слова в караоке. У трёх записей с ошибочным распознаванием использовано начало устойчивого сигнала уже выделенной дорожки вокала. Автоматические метки могут быть неточными.
- Кнопка «Звук вкл./выкл.» сохраняет выбор в браузере. Можно повторить или остановить фрагмент; при переходе к следующей картинке он останавливается.
- Игра с телефонами: комната ведущего, QR-приглашение, вход по нику и до 50 участников.
- Интерфейс с лёгкими японскими мотивами: бумажный фон, киноварные акценты, круглые печати и тонкие линии. Все игровые надписи на русском.
- Кнопка «Слайдшоу» справа сверху: семейный фотоальбом в случайном порядке и 26 полных песен из любимых на скриншотах. Следующая песня включается после окончания текущей. Фотографии и музыка проходят всю перемешанную подборку до повторения.
- Смена фото через 5, 8, 12 или 20 секунд, плавный переход, пауза, предыдущая/следующая фотография, другая песня, громкость и перемотка. Портреты сохраняются целиком. Закрытие слайдшоу останавливает музыку и возвращает к игре.
- Правильный ответ: `max(0, 100 − floor(время / 1 секунду))`. Например, за 5 секунд — 95 очков. Неверный ответ, отсутствие ответа и окончание 100 секунд — 0.
- Общий рейтинг после каждой третьей песни и в конце партии. Равенство очков разрешается по числу верных ответов, затем суммарному времени на верные ответы.
- Клавиши 1–4 для ответа, Enter для перехода после ответа.
- Адаптивный интерфейс для телефона, компьютера и телевизора. Кнопка полного экрана работает, если её поддерживает браузер.

Картинки-загадки созданы с помощью ИИ. Это самостоятельные интерпретации песен, а не официальные обложки или однозначные ребусы. Фотоальбом использует фотографии, предоставленные владельцем. Тексты песен не включены.

## Запуск

Опубликованная игра запускается обычным JavaScript-файлом с каталогом внутри него. Загрузка отдельных `.mjs`-модулей или `songs.json` для старта не требуется. Сетевой режим и его библиотеки инициализируются по нажатию. При ошибке загрузки или запуска появляется сообщение и кнопка «Обновить игру»; ожидание ограничено 12 секундами.

После изменения исходников пересоберите опубликованное приложение:

```sh
npm ci
npm run build
```

Сборка создаёт `app.<hash>.js` и `startup.<hash>.js`, обновляет ссылки в `index.html`. Имена с хешами позволяют браузеру получать новые версии без смешивания старых модулей.

```sh
python -m http.server 8767 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8767/ . На телефонах используйте опубликованную HTTPS-версию: адрес `127.0.0.1` относится к самому устройству.

## Компания с телефонами

1. Ведущий открывает игру на компьютере или телевизоре, выбирает подборку и длину партии, нажимает «Играть с телефонами».
2. Участники сканируют QR, вводят имя и ждут в комнате. Можно войти вручную по коду.
3. Ведущий начинает партию. После загрузки картинки у всех начинается общий отсчёт через 3 секунды.
4. У каждого один ответ. Ведущий считает время получения ответа. Результат открывается после всех ответов, по истечении 100 секунд или по команде ведущего.
5. Ведущий переключает картинки и рейтинги. Его вкладка должна оставаться открытой до конца партии.

Фрагмент звучит только у ведущего после общего открытия правильного ответа. Пока участники отвечают, музыка не включается. На телефонах участников она не воспроизводится. Если браузер ограничивает автоматический запуск, ведущий нажимает «Послушать». Повторные обновления комнаты не перезапускают фрагмент.

Это анонимные профили с именем в браузере, без паролей, восстановления аккаунта на другом устройстве и общего рейтинга между вечеринками. Возврат с прежним именем в прежнюю комнату на том же браузере сохраняет очки, пока ведущий держит её открытой. Новые участники входят до начала партии.

Интерфейс и медиа размещаются на VPS по `https://sim.fpimi.ru/karaoke/`. [Отдельный сервис комнат](server/README.md) использует порт 8102 внутри сервера. Публичное соединение: `wss://sim.fpimi.ru/karaoke/rooms`. Сервер считает время и очки. Разрешены origins основного сайта и зеркала GitHub Pages. Проверка 50 настоящих публичных соединений не заменяет проверку 50 физических телефонов в разных сетях.

Опубликованная игра использует обычный WebSocket к VPS, без WebRTC, STUN и TURN. Потеря связи ведущего ставит раунд на паузу до 90 секунд; возврат соединения сохраняет очки. При закрытии или обновлении вкладки ведущего нужна новая комната. При перезапуске сервиса комнаты теряются. Результаты относятся к текущей комнате. В исходниках сохранён прежний запасной транспорт PeerJS для конфигурации с пустым `RELAY_URL`.

PeerJS 1.5.5 и QRCode 1.5.4 включены локально в `vendor/realtime.mjs`; во время игры скрипты с CDN не подгружаются. Лицензии зависимостей сохранены в `vendor/THIRD_PARTY.txt`.

## Проверки

```sh
npm test
```

Проверяются состав данных, наличие изображений и 241 короткого фрагмента, уникальность вопросов и ответов, начисление очков, защита от двойного ответа, завершение партии, раздельные рекорды, границы секунд, общий запуск после загрузки, скрытие ответа, возврат участника, ограничения комнаты и рейтинги после 3/6 песен и в финале. Проверки аудио включают выключенный звук, повторные обновления комнаты, остановку при переходе, запрет автоматического воспроизведения и ошибку загрузки.

## Публикация

Основной сайт: VPS, `/karaoke/`. `server/pack-site.py` собирает только публичные файлы из точного Git-коммита, без исходников сервера, `.git`, настроек и локальной библиотеки. Архив и SHA-256-манифест проверяются перед публикацией. Caddy отдаёт статические файлы из отдельной директории выпуска и проксирует `/karaoke/rooms` и `/karaoke/health` сервису на 8102.

Зеркало GitHub Pages: ветка `main`, корень репозитория. Все пути относительные, поэтому оба адреса работают в своих подкаталогах.

Источником для механики стала игра [Mamma Mia Quiz](https://mupamuc.github.io/ITALLIANO_QUIZ/). Реализация и оформление созданы для этой музыкальной игры.

Состав публичного репозитория: код, названия песен, сжатые ИИ-изображения, 241 фрагмент MP3 по 15 секунд, фотоальбом и 26 полных перекодированных песен для слайдшоу. Архив фото, исходные файлы, пути к локальной библиотеке и настройки караоке не включены. У копий фотографий удалены EXIF/XMP, включая геометки; у музыки удалены исходные теги и выровнена громкость. Медиа загружаются при запуске соответствующего режима, а не при открытии игры. Фотоальбом публичный, как и сам сайт.
